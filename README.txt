YRN — BIRTHDAY LOVE EXPERIENCE

COMO USAR:
1. Abra o index.html no navegador.
2. Coloque suas fotografias na pasta fotos:
   foto1.jpg
   foto2.jpg
   foto3.jpg
   foto4.jpg
3. Se quiser música, coloque um arquivo MP3 em:
   musica/musica.mp3
4. Para alterar textos, abra index.html.
5. Para alterar a data da contagem, abra app.js e procure:
   2026-10-03T00:00:00

ESTRUTURA:
index.html
style.css
app.js
fotos/
musica/

O projeto não usa o vídeo enviado. A experiência é recriada em HTML/CSS/JS e combina o estilo romântico com a contagem de aniversário e a parte cósmica Libra + Escorpião.


ALTERAÇÃO DESTA VERSÃO:

NOTA SOBRE O CÓDIGO DO VÍDEO:
O vídeo mostra a execução do projeto e pequenos trechos de CSS, mas não contém o código-fonte completo. Por isso, a animação foi recriada com base no que é visualmente observável no vídeo, em vez de fingir que o código original foi extraído integralmente.


NOVA FUNÇÃO: tela inicial de acesso com animação de impressão digital. É uma simulação visual em JavaScript/CSS; não coleta nem valida dados biométricos reais.
